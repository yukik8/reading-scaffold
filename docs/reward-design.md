# 報酬設計ノート(2026-08-16)

演出(ドーパミンの出し方)の設計判断。W2実装とv1構想の指針。

## 言葉の原則(最上位。全演出に優先する)

**言葉で褒めない。言葉で教えない。** 教訓を言語化した瞬間に「教えられるもの」になり、
無意識下で植え付けられるものではなくなる。褒めも同じで、言葉で褒められて嬉しいのではなく、
雰囲気で嬉しくなるのが本物。Cognitive Exoskeletonの「照らす、答えない」の演出版。

- 出してよい言葉は**事実だけ**: 進捗%・経過分・正解の選択肢が光る(位置という事実)
- 報酬は**雰囲気**で伝える: きらきら・光・間。文はいらない
- **邪魔しない**(v0.5.0): 日常の星は本文の余白にだけ出す。均等に湧かせず、
  たまに一点で「キラッ」と固まって瞬く(予測不能・非単調)。文字の上を流れる
  全画面演出は大当たり・読了などのピーク時だけに限る
- 禁止: 相槌(「いい調子」)、労い(「おつかれさま」)、達成宣言(「読めた」)、
  解説・要点まとめ・教訓・アドバイス
- LLM生成物にも適用する(出題エンジンのプロンプトに「教えない」を明記)

## 二つのカテゴリ: 演出と記録

このプロダクトの視覚要素は必ずどちらかに属する。両方の性質を持つものは作らない。

| | 演出(stimulus) | 記録(record) |
|---|---|---|
| 例 | 星・ヒントカード・金の雨・お祝い | Mirror・署名リング・(v1)ペット |
| 法則 | **θ配下。θとともに連続的に漸減し、卒業(θ=0)で消える** | 永続してよい。ただし要求しない |
| 住処 | 読書中のページ上 | popup(Mirror)の中 |
| 可変報酬 | あり(乱数・レア度) | **禁止**(決定的な蓄積のみ) |

この二分法の理由: タペリングできない刺激装置を作ってはいけない(愛着が湧いたものはフェードアウトできない)。永続するものからは可変報酬ループを構造的に排除する。

### 帯(v0.8.4・記録カテゴリの段位表示)

制御からLevelは廃止したが、**表示としての段位**は武道の帯として復活させた。
自立度 = 1 − θ/θmax を節目で色に写す: 白(〜25%)→黄(〜50%)→緑(〜75%)→茶(〜100%)→**黒(卒業 θ=0)**。
言葉で褒めない — 色が段位を語る。実力(θの現在地)からのみ導出され、獲得も喪失も制御器の結果。

## パチスロの技法の移植基準

借りていいのは仕組み、借りてはいけないのは目的関数(滞在時間最大化)。

- **移植する**: 可変比率(いつ出るか=θ+乱数)、可変マグニチュード(レア度)、予告(期待の演出)
- **移植しない**: ニアミス(リーチ外れ=悔しさ駆動。「責めない」原則違反)、損失偽装、継続圧力(「連れ出さない」違反)

ドーパミンは報酬の受け取りではなく**予測誤差**で出る。だから頻度だけでなく大きさを予測不能にし、予告で期待の瞬間を作る。ただし予告は必ず当たる — 期待を裏切るのは良い方向だけ。

## 演出v2: 予期の設計(v0.11.0)

背景(docs/research/reward.md): ドーパミンは報酬の受け取りではなく**予測誤差とcue(予告)**で出る
(Schultz 1997)。しかも予期と絶頂は脳内でも別の系(Salimpoor 2011: 尾状核/側坐核)。
v1実装は予告→本演出が約1秒で、パチンコが最も磨いた「待ちの設計」が未使用だった。
v2は予期の窓を作る4つを追加する。いずれも「予告は必ず当たる」を保ったまま。

- **色の語彙**: 銀=通常 / 金=レア確定 / 虹=激レア確定。地の星・ヒントの星は銀に落とし、
  金以上を確定演出に限定する。外れ予告が存在しないため、色=大きさが100%信頼の語彙として
  言葉ゼロで学習される(パチンコの保留色=信頼度から、信頼度を100%に固定して移植)
- **先触れ**: レア度はヒント計画時に事前ロールし、レア以上が数段落先に待っていると
  地のきらきらが金(虹)に変わる。約1分以内の発火を保証(予告を裏切らない)
- **二度瞬き**: 激レア確定時のみ予告光が2回走る(擬似連の最小移植: 2段まで・1.5秒以内)
- **天井の一滴**: θ>0なのに演出ゼロの実読書が続いたら、次の区切りでnormal一回を確定
  (下限保証)。残り回転数の表示・示唆は移植しない — ハマリを期待に変える技法は
  滞在最大化の道具
- 併せてクイズはnormal枠からのみ化ける(金/虹の先触れをクイズにすり替えない)

**移植禁止の再確認**: リーチ(ニアミス前提)・確変/ラッシュ(継続圧力)・ゾーン(来訪圧力)・
音/振動・ストリーク。**PREEの含意**: 間欠強化は消去に強い(Humphreys 1939) —
θタペリングに構造的に有利。ただし守られるのは「読む行動」であって演出への愛着ではない。
θ低下とともに、随伴性の重心を「読む→光」から「わかる→光」(クイズ・将来の問いの種)へ移す。

## レア度階層(v0.3.0で実装)

ヒント発火時にロール。頻度はθが決め、レア度は大きさだけを変える。

| tier | 確率 | 演出 | 記録 |
|---|---|---|---|
| normal | 約86% | 星の三波 | hint_shown |
| rare | 12% | 予告の光→金の雨 | hint_shown + effect_shown(rain_rare) |
| epic | 2.5% | 予告の光→濃い金の雨+縁光 | hint_shown + effect_shown(rain_epic) |

`effect_shown`に記録するので、レア演出が出たセッションは「補助あり」に正しく分類される。tier別の離脱率・継続率は後で分析できる。

### クイズ正解の大当たり(v0.4.2)

理解への報酬は最大瞬間風速にする。ただし強さは**θ連動**で、卒業に向けて漸減する:

| θ | 正解時の演出 |
|---|---|
| θ≥5 | **大当たり**: 予告→縁光二連→特濃の雨130粒+星の三波(約5秒) |
| θ≥3 | 予告→金の雨 |
| それ未満 | 星の二波のみ |

ヒント枠の乱数レア度と違い、こちらは「理解の証明」への確定報酬。確率でなくθで強さが決まる。
記録は effect_shown(quiz_jackpot / quiz_rain)。

## ペット案(卵→育つ)の扱い — v1判断

魅力: 蓄積の可視化、「育てる」哲学との一致、読書メモリの具象化。
リスクの正体: 依存そのものより**タペリング不能**なこと。+動機の乗り換え(ペットのために読む=overjustification)、世話圧力(loss aversion=「責めない」違反)。

置き場所を決めたので条件付きで採用可: **記録カテゴリに置く**。

- 読むほど育つ一方向の蓄積のみ。減衰・空腹・死・要求なし
- 住処はpopup(Mirror)。読書中の視界に入らない
- 卒業(θ=0)で完成体 = 卒業の記念(署名リングの具象版)

この条件を1つでも破る設計変更(例: ページ端に常駐させる、衰弱を入れる)は二分法違反なので却下。
